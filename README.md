# REPTILE NOTE v0.4.5 ユーザーガイド

爬虫類の個体情報、飼育環境、日々の記録、予定、写真を管理するアプリです。

## 主な機能
- ホーム：測定、ごはん、脱皮、排泄、温度、湿度、お掃除、その他の状況を個体ごとに表示。
- ごはん：最後の給餌からの日数と、前回の給餌からの間隔を表示。結果は「食べた」「食べなかった」「一部食べた」「吐いた」から選択。
- 脱皮：状態に応じて〇・△・⚠を表示し、最後の脱皮からの日数と前回からの日数を表示。
- 温度：HOT・COOLを同じ記録で入力。湿度は独立して記録。
- 測定：体重・長さを片方または両方入力。
- 個体・飼育環境・飼育記録・カレンダー・写真・設定の管理。

## 数値入力
数値入力欄の増減ボタンを、アプリの濃紺・黄緑の配色に合わせたカスタムデザインに変更しています。＋／−ボタンまたはキーボードで値を調整できます。

## データ保存
現在のデータはブラウザ内に保存され、端末間の自動同期には対応していません。更新前には「設定」→「データ管理」からバックアップを保存してください。

## 更新方法
ZIPを展開し、`index.html`、`sw.js`、`manifest.webmanifest`をGitHub Pagesのリポジトリへ上書きしてください。キャッシュ更新のため`sw.js`も必ず更新してください。

## プルダウン
選択欄を濃紺の背景、角丸、黄緑の矢印とフォーカス表示に統一しました。選択肢の色もアプリの配色に合わせています。


## カレンダーの凡例
カレンダーの凡例を2列から4列に変更し、スマートフォンでも4項目ずつ並ぶようにしました。

## ホームのサブ情報
ごはん・脱皮・排泄・お掃除の経過日数や前回との間隔は、小さな補足文字で表示します。測定は体重・長さの現在値を大きく表示し、前回との差（＋／−）を小さな補足文字で表示します。履歴がない項目は「未記録」と表示します。


## 日付入力
誕生日・お迎え日などの日付入力は、年を4桁（0001〜9999）に制限しています。
