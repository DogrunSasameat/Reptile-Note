# REPTILE NOTE v0.4.1 ユーザーガイド

爬虫類の個体情報、飼育環境、日々の記録、予定、写真をまとめて管理するアプリです。

## 飼育記録の種類
記録タイプは次の8種類です。
1. 測定（体重・長さ）
2. ごはん
3. 脱皮
4. 排泄
5. 温湿度（HOT・COOL・湿度）
6. お掃除
7. 健康・通院
8. その他

「メモ」は独立した記録タイプではなく、「その他」に含めます。以前の「メモ」記録は削除せず、一覧では「その他」として扱います。

## 主な機能
- **ホーム**：測定、ごはん、脱皮・排泄、HOT温度、COOL温度、湿度、お掃除、その他を表示します。
- **個体**：個体情報の登録・編集・削除。
- **飼育環境**：ケージや保温器具、目標温湿度などを個体ごとに管理。
- **飼育記録**：記録の追加・編集・削除。
- **カレンダー**：日付ごとの記録・予定を確認。繰り返し予定にも対応。
- **写真・ギャラリー**：写真を個体・日付・タイトル・メモと一緒に保存。
- **設定**：飼い主情報、病院情報、通知、データ管理。

## データ保存について
現在のデータはブラウザ内に保存され、端末間の自動同期には対応していません。更新前には「設定」→「データ管理」からバックアップを保存してください。

## 更新方法
ZIPを展開し、`index.html`、`sw.js`、`manifest.webmanifest`をGitHub Pagesのリポジトリへ上書きしてください。キャッシュ更新のため`sw.js`も必ず更新してください。
