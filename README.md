# REPTILE NOTE v0.4.40

REPTILE NOTEは、爬虫類の個体情報・飼育環境・日々の記録・予定・写真をまとめて管理する飼育ノートです。スマートフォンとPCのブラウザで利用できます。

## できること

- **個体管理**：名前、種類、性別、お迎え日、誕生日、モルフ、プロフィールメモ、写真などを登録
- **飼育環境の記録**：ケージ、保温器具、サーモスタット、床材、シェルター、その他の設備や環境メモを管理
- **日々の記録**：体重、温度・湿度、排泄、脱皮、お掃除、食事、健康・通院などを記録
- **予定管理**：通院やメンテナンスなどの予定を登録
- **プロフィール写真**：ホーム画面の個体写真をタップして変更。共有ノートではSupabase Storageに保存
- **共有ノート**：共有リンクを発行し、参加者を招待

## はじめかた

1. GitHub Pagesで公開したアプリのURLをブラウザで開きます。
2. 初回設定が表示されたら、案内に沿って飼い主情報と飼育ノートを設定します。
3. 個体を登録すると、飼育記録や環境情報、写真などを追加できます。
4. スマートフォンではブラウザのメニューから「ホーム画面に追加」または「アプリをインストール」を選ぶと、ホーム画面から起動できます。

## ノートの共有

1. オーナー端末で「設定」→「共有・参加者管理」を開きます。
2. 参加者の権限（閲覧のみ／編集可能）、リンクの有効期限、利用上限を選んで共有リンクを発行します。
3. 発行したURLを参加してほしい相手に送ります。
4. 相手はURLを開き、ニックネームを入力して参加します。

- **オーナー**：共有リンクの発行や参加者の確認など、ノート全体を管理します。
- **編集可能**：共有ノートの情報を追加・編集できます。
- **閲覧のみ**：共有された情報を閲覧できます。編集や削除はできません。
- 共有リンクは、知っている人がノートに参加できる招待情報です。必要な相手にだけ送ってください。

## データ同期について

共有ノートでは、個体情報・記録・予定などの対応データがクラウドと同期されます。個体のプロフィール写真はSupabase Storageにアップロードされ、共有ノートの参加者にも表示されます。

通信状況などにより同期に失敗する場合があります。大切な情報を編集した後は、画面上の同期状態や表示内容を確認してください。

## データを守るために

- ブラウザのサイトデータやアプリのストレージを消去すると、端末内に保存されたデータやセッション情報が失われることがあります。必要がない限り消去しないでください。
- 共有リンクや端末のアクセス情報は他人に渡さないでください。
- 端末変更・ブラウザ変更の前には、必要なデータが共有ノートに同期されていることを確認してください。
- このバージョンには、従来の端末内ノートを後からクラウドへ移行する機能はありません。新しく共有ノートを作成して利用する構成です。

## このバージョンについて（v0.4.40）

- 写真ギャラリー機能を画面から削除
- ホーム画面の個体プロフィール写真をタップして編集できるよう変更
- プロフィール写真をSupabase Storageに保存し、共有ノートで同期
- 旧版の端末内プロフィール写真は初回クラウド同期時にStorageへ移行
- プロフィール画像をアップロード前に圧縮し、容量を削減
- ホーム画面に追加したときのアプリアイコンを設定
- 個体情報・記録・予定のクラウド同期に対応
- 記録・予定の削除をクラウドに反映
- 既存ノートのクラウド移行機能は搭載していません
