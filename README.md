# REPTILE NOTE v0.4.5 ユーザーガイド

爬虫類の個体情報、飼育環境、日々の記録、予定、写真を管理するアプリです。

## 主な機能
- ホーム：測定、ごはん、脱皮、排泄、温度、湿度、お掃除、その他の状況を個体ごとに表示。
- ごはん：最後の給餌からの日数と、前回の給餌からの間隔を表示。結果は「食べた」「食べなかった」「一部食べた」「吐いた」から選択。
- 脱皮：状態に応じて〇・△・⚠を表示し、最後の脱皮からの日数と前回からの日数を表示。
- 温度：HOT・COOLを同じ記録で入力。湿度は独立して記録。
- 測定：体重・長さを片方または両方入力。
- 個体・飼育環境・飼育記録・カレンダー・写真・設定の管理。

## 数値入力
数値入力欄の増減ボタンを、アプリの濃紺・黄緑の配色に合わせたカスタムデザインに変更しています。＋／−ボタンまたはキーボードで値を調整できます。

## データ保存
現在のデータはブラウザ内に保存され、端末間の自動同期には対応していません。更新前には「設定」→「データ管理」からバックアップを保存してください。

## 更新方法
ZIPを展開し、`index.html`、`sw.js`、`manifest.webmanifest`をGitHub Pagesのリポジトリへ上書きしてください。キャッシュ更新のため`sw.js`も必ず更新してください。

## プルダウン
選択欄を濃紺の背景、角丸、黄緑の矢印とフォーカス表示に統一しました。選択肢の色もアプリの配色に合わせています。


## カレンダーの凡例
カレンダーの凡例を2列から4列に変更し、スマートフォンでも4項目ずつ並ぶようにしました。

## ホームのサブ情報
ごはん・脱皮・排泄・お掃除の経過日数や前回との間隔は、小さな補足文字で表示します。測定は体重・長さの現在値を大きく表示し、前回との差（＋／−）を小さな補足文字で表示します。履歴がない項目は「未記録」と表示します。


## 日付入力
誕生日・お迎え日などの日付入力は、年を4桁（0001〜9999）に制限しています。


## 修正履歴 v0.4.18
ホーム表示でその他の記録件数を参照する変数が未定義だった問題を修正しました。個体情報・記録データの保存形式は変更していません。


## 修正履歴 v0.4.18
保存データ読み込み時に個体・記録・予定・写真の配列を検証し、不足や不正な要素を安全に扱うようにしました。また、各画面の描画を独立して実行し、一つの画面でエラーが起きても他の画面（個体一覧・カレンダー等）が表示されるようにしました。既存の保存データを初期化する処理は含みません。

## 日付入力・カレンダー
日付欄は4桁の西暦を含む形式で常に表示し、カレンダーアイコンからアプリ配色に合わせたカスタムカレンダーを開けます。日付・日時の入力に対応し、記録日時では時刻も選べます。

## ホームタイルの編集動作
脱皮の状態は 🟢（きれいに脱皮）、🟡（一部残りあり）、⚠️（脱皮不全・要観察）で表示します。ホームの記録タイルをタップすると、該当個体の同種記録がある場合は最新の記録を編集し、まだ記録がない場合のみ新規追加します。


## 修正履歴 v0.4.18
日付ピッカーをモーダルダイアログ（ブラウザのトップレイヤー）として表示するよう変更。飼育記録などのダイアログより背面に隠れる問題を修正しました。


## 個体情報の日付欄
個体編集画面の性別・お迎え日の横並びを調整し、お迎え日の日付全体が見えるように入力欄を広げました。

## ホームの表示対象日
ホームの飼育記録タイルは、今日の日付で登録された記録だけを表示します。過去の日付の記録は記録一覧・カレンダーには残りますが、今日のホーム表示には出しません。今日の記録がない場合は「未記録」と表示します。ホームタイルをタップした場合も、今日の記録があれば編集し、なければ新規追加します。


## 脱皮状態アイコン
ホームの脱皮状態表示を、きれいに脱皮＝⭐、一部残りあり＝⭕、脱皮不全・要観察＝⚠️ に変更しました。

## ホームの過去記録表示
ホームの大きな文字は今日入力した値・状態だけを表示します。今日の記録がない場合は大きな文字を「--」にし、補足欄に最新の過去記録からの経過日数（例：5日前に脱皮、3日前に食べた、2日前に測定）を表示します。記録自体は削除せず、記録一覧・カレンダーに残ります。
