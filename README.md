# REPTILE NOTE v0.4.27

## 変更点
- 初回起動時のサンプル個体自動登録を停止（既存のlocalStorageデータは維持）
- オーナーが個体を追加・編集すると、セッショントークンが設定済みの場合にSupabaseへ保存
- 既存の端末内個体を共有サーバーへ一括同期する操作を追加
- 共有URL参加後およびゲスト再読み込み時に、共有ノートの個体一覧を取得
- 閲覧のみゲストには個体の追加・編集・削除操作を表示しない
- ゲスト側の共有個体データで端末のlocalStorageを上書きしない

## 注意
- Supabaseのguest-apiに `save_pet` と `list_pets` がデプロイ済みであることが必要です。
- 写真ファイルのクラウド同期は未対応です（写真はこの段階では同期しません）。
- 記録・予定・写真・その他の飼育データ同期は未対応です。
- オーナーのトークンは共有・参加者管理画面で入力し、参加者一覧の読み込み等を行うと、このタブのsessionStorageに保持されます。
- 既存のローカルデータは削除しません。初回起動時のサンプル個体だけを新規生成しないようにしています。
