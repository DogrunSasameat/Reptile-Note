# REPTILE NOTE v0.4.29

飼育記録のクラウド共有を追加しました。

## 変更点
- 共有ノート参加者は飼育記録をSupabaseから読み込みます。
- オーナー・編集可能ゲストが記録を追加／編集すると `save_record` APIへ保存します。
- 設定の共有・参加者管理に、端末内の既存記録をまとめて同期するボタンを追加しました。
- 閲覧のみゲストには記録編集操作を表示しません。
- 共有セッション中は記録削除を表示しません（削除APIは未実装）。
- 写真は今回のクラウド同期対象外です。ローカルには従来どおり保存されます。

## 注意
既存の飼育記録を共有するには、オーナー側で「この端末の飼育記録を共有サーバーへ同期」を実行してください。
端末内の記録は削除しません。

- 補正マーカーは画面表示時に取り除き、既存の記録内容は変更しません
