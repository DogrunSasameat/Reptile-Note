# REPTILE NOTE
## ユーザーガイド

REPTILE NOTEは、爬虫類の個体情報・飼育記録・飼育環境・写真・予定をまとめて管理するためのアプリです。

---

## 1. はじめに

1. GitHub Pagesで公開したREPTILE NOTEをブラウザで開きます。
2. 下部メニューの「個体」から、飼育している個体を登録します。
3. 個体を登録したら、「環境」でケージや温湿度管理の情報を登録します。
4. 日々の出来事は「ホーム」のクイックボタン、または「記録」から追加できます。

個体を登録すると、ホーム上部で表示する個体を切り替えられます。複数飼育の場合も、個体ごとに情報を管理できます。

## 2. ホーム

ホームでは、選択中の個体の飼育状況と最近の記録を確認できます。

### 表示できる項目
- 年齢
- お迎えからの日数
- 長さ
- 体重
- ご飯
- 排泄
- 温度
- 湿度
- お掃除
- その他の記録件数

「項目を編集」から、ホームに表示する項目をオン・オフできます。表示設定はホームの見た目だけに反映され、記録そのものは削除されません。

### クイック記録
ホーム下部のボタンから、よく使う記録をすぐに追加できます。
- ご飯
- 排泄
- 測定
- 温湿度
- お掃除

「測定」では、体重と長さを片方だけ、または両方まとめて入力できます。

## 3. 個体

「個体」では、飼育している生体を登録・編集できます。

登録できる情報：
- 名前
- 種類
- 性別
- お迎え日
- 誕生日
- モルフ
- メモ
- 写真

個体を削除すると、その個体に関連付けられた飼育記録と予定も削除されます。削除前に内容を確認してください。

## 4. 飼育環境

「環境」では、個体ごとに飼育設備や環境情報を記録できます。

登録できる情報：
- ケージ・飼育容器の種類や製品名
- サイズ・寸法、素材・特徴
- 保温器具
- サーモスタット
- 目標温度・湿度
- 床材
- シェルター
- 水入れ
- 照明・UVB
- その他の設備・レイアウト
- 環境メモ

個体ごとに「編集」から入力・更新してください。

## 5. 飼育記録

「記録」では、個体や記録タイプで絞り込んで、過去の記録を確認できます。記録の追加時には、個体・種類・日時・メモ・写真などを登録できます。

記録タイプ：
- 温湿度：温度、湿度、測定場所
- 測定：体重（g）、長さ（cm）。どちらか一方だけでも登録できます
- 給餌：餌の種類・サイズ、食べた／食べなかった等の結果
- 体重、長さ：個別の記録形式も選択できます
- 脱皮：脱皮の状態
- 排泄：うんち、おしっこ（尿酸）、両方
- お掃除：掃除した内容
- その他：タイトルと内容
- 健康・通院：状態・症状・処置
- メモ：自由記入

記録には日時、メモ、写真を追加できます。不要な記録は削除できます。

## 6. カレンダー・予定

「予定」ではカレンダーから日付ごとの飼育記録・予定・記念日を確認できます。

- 日付をタップすると、その日の記録や予定を確認できます。
- 日付の詳細画面から、その日付の飼育記録や予定を追加できます。
- 「予定追加」から、予定名・日時・対象個体・メモを登録できます。
- 個体に登録した誕生日とお迎え日は、カレンダーに記念日として表示されます。

カレンダーの凡例は、給餌・脱皮・排泄・測定・温湿度・健康・誕生日などの目印です。

## 7. 写真・ギャラリー

「写真」では、飼育記録に添付した写真と、ギャラリーに直接追加した写真をまとめて確認できます。

「写真を追加」から、次の情報を登録できます。
- 対象個体
- 写真
- 撮影日・記録日
- タイトル
- メモ

写真はアプリ内で表示用に圧縮して保存されます。ギャラリーに直接追加した写真は、ギャラリーから削除できます。飼育記録に添付した写真は、元の記録に紐づいています。

## 8. 設定

画面上部の歯車ボタンから設定を開けます。

### 飼い主情報
ニックネーム、年齢、性別、SNSを登録できます。

### 病院情報
かかりつけ病院の名前、電話番号、住所、診療時間・休診日、Webサイト、メモを登録できます。

### 通知
ブラウザの通知許可を確認できます。現在は、アプリを開いた際に今日・明日の誕生日とお迎え記念日を確認して通知する方式です。アプリを閉じている間の通知には対応していません。

### データ管理
- **データをバックアップ**：個体・記録・予定などのデータをJSONファイルとして書き出します。
- **バックアップを復元**：JSONバックアップからデータを復元します。復元すると現在のデータはバックアップ内容に置き換わります。
- **すべてのデータを削除**：保存データを削除します。取り消せないため、実行前に必ずバックアップしてください。

### 表示設定
ライトモード／ダークモードの切り替え項目はありますが、現在は今後対応予定の案内表示です。

## 9. データの保存と注意点

- 現在のデータは、アプリを開いているブラウザ内（端末ごと）に保存されます。
- スマートフォンとパソコンのデータは自動同期されません。
- 別の端末やブラウザで開いても、同じデータが自動的に表示されるわけではありません。
- ブラウザの閲覧データ・サイトデータを消去すると、アプリのデータが失われる場合があります。
- アプリを更新するときは、事前に「設定」→「データ管理」からバックアップを保存してください。
- GitHub Pagesのファイルを更新するだけであれば、通常はブラウザ内の保存データは引き継がれます。更新時にサイトデータを消去しないでください。

## 10. アプリの更新方法（管理者向け）

1. 配布されたZIPファイルを展開します。
2. 展開したファイルをGitHub Pagesのリポジトリにアップロードし、既存ファイルを上書きします。
3. GitHub Pagesの公開反映後、ブラウザで再読み込みします。
4. 更新前に保存したバックアップがあることを確認してから作業してください。
