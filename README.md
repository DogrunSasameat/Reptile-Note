# REPTILE NOTE v0.3.9 ユーザーガイド

爬虫類の個体情報、飼育環境、日々の記録、予定、写真をまとめて管理するアプリです。

## 主な機能
- **ホーム**：個体ごとの飼育状況を表示。年齢・お迎え日数に続き、測定、ご飯、排泄、温湿度、お掃除、その他を表示します。測定パネルから体重・長さをまとめて記録でき、前回との差も確認できます。
- **個体**：個体情報の登録・編集・削除。お迎え日や誕生日、写真などを管理します。
- **飼育環境**：ケージ、保温器具、サーモスタット、目標温湿度、床材、シェルターなどを個体ごとに登録。ケージ寸法は幅×奥行×高さをcm単位で別々に入力します。
- **飼育記録**：測定、給餌、排泄、温湿度、お掃除、その他、脱皮、健康・通院、メモなどを登録。記録の編集・削除ができます。
- **カレンダー**：日付をタップして、その日の記録・予定を確認。日付画面から予定の追加・編集・削除ができます。毎月指定日、毎月第○曜日、毎月末日の繰り返し予定に対応しています。
- **写真・ギャラリー**：写真を個体・日付・タイトル・メモと一緒に保存できます。
- **設定**：飼い主情報、病院情報、通知、データ管理など。

## 測定記録
「測定」を選ぶと、体重（g）と長さ（cm）を入力できます。どちらか一方だけでも、両方同時でも記録できます。以前に登録した「体重」「長さ」の記録はデータとして保持され、過去記録の表示にも対応します。

## 繰り返し予定
カレンダーで日付を選び「この日に予定を追加」を選択します。「繰り返しの予定」をオンにすると、毎月○日、毎月第○曜日、毎月末日を設定できます。繰り返し予定を編集・削除すると、その予定の繰り返し設定全体に反映されます。

## データ保存について
現在のデータはブラウザ内に保存され、端末間の自動同期には対応していません。ブラウザのサイトデータを消すと記録が失われる場合があります。更新前には「設定」→「データ管理」からバックアップを保存してください。

## 更新方法
ZIPを展開し、`index.html`、`sw.js`、`manifest.webmanifest`をGitHub Pagesのリポジトリへ上書きしてください。キャッシュ更新のため`sw.js`も必ず更新してください。
