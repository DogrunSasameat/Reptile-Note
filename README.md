# REPTILE NOTE v0.4.23

## 今回の更新
- 共有URLの `?share=...` を検出してゲスト参加ダイアログを表示
- ニックネームを入力して `guest-api` の `join_workspace` を呼び出し
- 発行されたゲストセッショントークン、workspace ID、権限、ニックネームを sessionStorage に保存
- 招待トークンは画面で受け取った直後にアドレスバーから除去
- 参加後、飼育データの共有・同期は次の実装段階であることを明示

## 注意
この版は共有URLからゲスト参加登録を行う段階です。共有ワークスペースの飼育データ読み込み・書き込み・同期はまだ実装されていません。ゲストのローカルデータとオーナーのデータは自動統合されません。
