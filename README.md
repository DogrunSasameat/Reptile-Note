# REPTILE QUEST (prototype 0.1.0)

爬虫類の飼育記録を管理する、スマートフォン向けPWAプロトタイプです。

## 含まれる機能
- 複数個体の登録・編集・削除
- 温湿度、給餌、体重、脱皮、排泄、健康・通院、メモの記録
- 記録への写真添付
- カレンダー予定の登録
- カレンダー上に給餌・脱皮・排泄・体重・温湿度・健康記録をアイコン表示
- 誕生日・お迎え記念日を毎年カレンダーに自動表示
- 誕生日・お迎え記念日の当日／前日通知（アプリ起動時・通知許可時）
- 誕生日からの年齢、お迎えからの日数を自動計算
- JSONバックアップ・復元
- ブラウザ内保存（localStorage）
- Service Workerによる基本的なオフラインキャッシュ

## 公開方法（無料）
1. GitHubで新しいPublicリポジトリを作成
2. このZIPの中身をリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch
4. Branchを `main`、folderを `/ (root)` にしてSave
5. 数分後に表示されるURLをスマートフォンのChromeで開く
6. Chromeメニューから「ホーム画面に追加」

## データについて
データは利用者の端末・ブラウザ内に保存されます。アプリを公開しても、利用者同士でデータが共有されることはありません。
ブラウザデータの消去・端末故障・ブラウザ変更で失われる可能性があるため、設定画面から定期的にJSONバックアップを取得してください。

## 現時点の制限
- ログイン・クラウド同期なし
- 通知はアプリ起動時に今日・明日の誕生日／お迎え記念日を確認する方式。アプリを閉じている間の確実な通知配信は未実装
- 写真はブラウザ内ストレージに保存されるため、大量の写真で容量を使います
- 本番公開前に、複数ブラウザ・端末でのテスト、アクセシビリティ、プライバシーポリシー等の整備が必要です
